QCustomEmptyState

QCustomEmptyState — a centered "nothing here yet" placeholder.

A mark + title + description + an optional action button. Tokenized. Emits actionClicked.

The default mark is PAINTED, not a glyph. An emoji does not tint with the theme, does not scale cleanly, and renders as a different picture on every platform - the same reasoning as QCustomSparklesText's drawn star. setIcon() still accepts a string for anyone who wants one.

Import​

from Custom_Widgets.QCustomEmptyState import QCustomEmptyState

Also available from the Qt Designer palette — every property below is settable in Designer and saved into the .ui file.

Constructor​

QCustomEmptyState(parent=None, icon=None, title='Nothing here yet', description='')
