QCustomDonut

A painted donut / multi-ring radial chart.

Two modes: mode="rings" (default) - CONCENTRIC gauge rings, one per value: each value is its own ring at a decreasing radius, sweeping an arc proportional to value / max(values) over a faint track, with rounded caps. This is the "several rings" radial-bar look (outer = largest value). mode="segments" - a single ring split into coloured segments (a classic donut), rounded caps + gaps.

Painted directly with QPainter, so it stays crisp at ANY size (a QChart pie collapses to a hairline in constrained panels). Give values/colours via setData(...) in code, or the valuesCsv / colorsCsv properties in Qt Designer.

At a glance​

Quick start​

from Custom_Widgets.QCustomDonut import QCustomDonut

widget = QCustomDonut()

Dark theme​

Colours come from the design tokens, so the widget follows the app theme with no extra work.
