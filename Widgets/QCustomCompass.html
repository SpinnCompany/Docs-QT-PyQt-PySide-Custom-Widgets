QCustomCompass

A heading / compass rose.

A painted compass: a tick ring with N / E / S / W (+ intercardinals), a two-tone needle and a centre readout (16-point cardinal + degrees). Set the heading (0-360°, 0 = North = up); it eases to the new bearing when animated.

Two looks (rotateBezel): False (default) - a FIXED rose, the needle rotates to the heading. True - a rotating COMPASS CARD: the needle stays up and the whole rose spins so the heading sits at the top (aircraft / marine style).

Interactive: drag around the centre to set the heading (opt-out via interactive=False). Painted with QPainter; it FLEXes to the widget and every colour is a qproperty so it flips with the theme. Signal: headingChanged(float).

Quick start​

from Custom_Widgets.QCustomCompass import QCustomCompass

widget = QCustomCompass()

Dark theme​

Colours come from the design tokens, so the widget follows the app theme with no extra work.
