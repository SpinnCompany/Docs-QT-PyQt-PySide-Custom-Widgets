# AcrylicEffect

## Overview

:::info
**Windows 11 Fluent Design**: `AcrylicEffect` brings the signature frosted glass transparency from Microsoft's Fluent Design System to Qt applications, creating modern, professional user interfaces.
:::

`AcrylicEffect` is a comprehensive implementation of Windows 11-style acrylic blur effects for Qt applications. It provides realistic frosted glass transparency with multiple layers including background blur, tint color, luminosity, and noise texture.

---

## Features

:::success
**Professional Grade**: Production-ready acrylic effects with robust fallback mechanisms and multi-monitor support.
:::

- **Realistic Acrylic Material**: Windows 11-style frosted glass effect
- **Multi-Layer Composition**: Blur + tint + luminosity + noise layers
- **Multi-Monitor Support**: Proper screen grabbing across multiple displays
- **Performance Optimized**: Efficient blur algorithms with image scaling
- **Programmatic Noise**: Dynamic noise texture generation
- **Color Analysis**: Intelligent dominant color extraction
- **Robust Fallbacks**: Graceful degradation when effects fail

## Basic Usage

### Simple Acrylic Effect

:::tip
**Quick Start**: This basic example demonstrates the minimal setup required to apply acrylic effects to any widget.
:::

```python
from Custom_Widgets.AcrylicEffect import AcrylicEffect
from qtpy.QtWidgets import QApplication, QMainWindow, QWidget, QVBoxLayout, QLabel
from qtpy.QtGui import QColor

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        
        # Create central widget
        central = QWidget()
        self.setCentralWidget(central)
        layout = QVBoxLayout(central)
        
        # Add some content
        label = QLabel("Acrylic Effect Demo")
        label.setAlignment(Qt.AlignCenter)
        label.setStyleSheet("font-size: 24px; color: white;")
        layout.addWidget(label)
        
        # Apply acrylic effect
        self.acrylic = AcrylicEffect(
            widget=central,
            blurRadius=15,
            tintColor=QColor(242, 242, 242, 150),
            luminosityColor=QColor(255, 255, 255, 10),
            noiseOpacity=0.03
        )
        
        # Grab background from screen
        self.acrylic.grabFromScreen()

app = QApplication([])
window = MainWindow()
window.resize(600, 400)
window.show()
app.exec_()
```

## Class Reference

### AcrylicEffect

:::info
**Main Entry Point**: The `AcrylicEffect` class is the primary interface for applying acrylic effects to widgets. It manages the complete effect pipeline.
:::

Main class for applying acrylic effects to widgets.

#### Constructor

```python
AcrylicEffect(
    widget: QWidget,
    blurRadius: int = 15,
    tintColor: QColor = QColor(242, 242, 242, 150),
    luminosityColor: QColor = QColor(255, 255, 255, 10),
    noiseOpacity: float = 0.03
)
```

**Parameters:**
- `widget`: Target widget to apply the effect to
- `blurRadius`: Gaussian blur radius (5-30 typical)
- `tintColor`: Base tint color with alpha
- `luminosityColor`: Luminosity layer color
- `noiseOpacity`: Noise texture opacity (0.0-1.0)

### GaussianBlurUtils

:::warning
**Performance Critical**: The blur operations can be computationally expensive. Use the `blurPicSize` parameter to optimize performance for large images.
:::

Static utility class for image blur operations.

#### Methods

```python

    image,           # Path, QPixmap, or QImage

# Convert Qt images to PIL format
```

```python
class AcrylicSidebar(QWidget):

                    color: white;

                }
                QPushButton:hover {
                    background: rgba(255,255,255,50);

            widget=self,

        content.setStyleSheet("font-size: 24px; color: white;")

        sidebar = self.findChild(AcrylicSidebar)
```

### Dynamic Acrylic Dashboard

:::tip
**Dashboard Design**: Use varying tint colors for different dashboard panels to create visual distinction while maintaining cohesive acrylic aesthetics.
:::

```python
class AcrylicDashboard(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Acrylic Dashboard")
        self.resize(1000, 700)
        
        self.setup_ui()
        self.setup_acrylic_effects()
    
    def setup_ui(self):
        central = QWidget()
        central.setStyleSheet("background: #1a1a1a;")
        self.setCentralWidget(central)
        
        layout = QGridLayout(central)
        
        # Create multiple acrylic panels
        panels = [
            ("Statistics", 0, 0), ("Charts", 0, 1),
            ("Recent Activity", 1, 0), ("Notifications", 1, 1)
        ]
        
        self.acrylic_panels = []
        
        for title, row, col in panels:
            panel = QWidget()
            panel.setFixedSize(300, 200)
            panel.setStyleSheet("border-radius: 10px;")
            
            panel_layout = QVBoxLayout(panel)
            label = QLabel(title)
            label.setStyleSheet("color: white; font-size: 16px; font-weight: bold;")
            panel_layout.addWidget(label)
            
            layout.addWidget(panel, row, col)
            self.acrylic_panels.append(panel)
    
    def setup_acrylic_effects(self):
        colors = [
            QColor(255, 100, 100, 80),   # Red tint
            QColor(100, 255, 100, 80),   # Green tint  
            QColor(100, 100, 255, 80),   # Blue tint
            QColor(255, 255, 100, 80)    # Yellow tint
        ]
        
        self.acrylic_effects = []
        
        for i, panel in enumerate(self.acrylic_panels):
            effect = AcrylicEffect(
                widget=panel,
                blurRadius=25,
                tintColor=colors[i],
                luminosityColor=QColor(255, 255, 255, 20),
                noiseOpacity=0.05
            )
            effect.applyToWidget()
            self.acrylic_effects.append(effect)
        
        # Grab backgrounds after window is shown
        QTimer.singleShot(100, self.grab_backgrounds)
    
    def grab_backgrounds(self):
        for effect in self.acrylic_effects:
            effect.grabFromScreen()
```

### Color-Aware Acrylic Effect

:::info
**Intelligent Adaptation**: This example demonstrates how to automatically adapt acrylic parameters based on background content for optimal visual results.
:::

```python
class SmartAcrylicWidget(QWidget):
    def __init__(self, background_image=None):
        super().__init__()
        self.background_image = background_image
        self.setup_ui()
    
    def setup_ui(self):
        layout = QVBoxLayout(self)
        
        # Content
        label = QLabel("Smart Acrylic")
        label.setAlignment(Qt.AlignCenter)
        label.setStyleSheet("font-size: 18px; font-weight: bold; color: white;")
        layout.addWidget(label)
        
        # Apply intelligent acrylic effect
        self.apply_smart_acrylic()
    
    def apply_smart_acrylic(self):
        if self.background_image:
            # Extract dominant color from background
            dominant_rgb = AcrylicEffect.getDominantColor(self.background_image)
            dominant_color = QColor(*dominant_rgb)
            
            # Create tint color based on dominant color
            tint_color = QColor(
                dominant_color.red(),
                dominant_color.green(), 
                dominant_color.blue(),
                80  # Semi-transparent
            )
            
            # Adjust luminosity based on brightness
            brightness = (dominant_color.red() * 0.299 + 
                         dominant_color.green() * 0.587 + 
                         dominant_color.blue() * 0.114)
            
            if brightness > 128:
                luminosity_color = QColor(0, 0, 0, 10)  # Darker for bright backgrounds
            else:
                luminosity_color = QColor(255, 255, 255, 15)  # Lighter for dark backgrounds
            
        else:
            # Default colors
            tint_color = QColor(150, 150, 200, 100)
            luminosity_color = QColor(255, 255, 255, 15)
        
        # Apply acrylic effect
        self.acrylic = AcrylicEffect(
            widget=self,
            blurRadius=20,
            tintColor=tint_color,
            luminosityColor=luminosity_color,
            noiseOpacity=0.04
        )
        self.acrylic.applyToWidget()
        
        if self.background_image:
            self.acrylic.setImage(self.background_image)
        else:
            self.acrylic.grabFromScreen()
```

## Troubleshooting

### Common Issues

:::danger
**Critical Issues**: Address these common problems immediately if your acrylic effects are not working as expected.
:::

**Effect not appearing:**
- Ensure `applyToWidget()` is called
- Verify widget has proper size and is visible
- Check that `grabFromScreen()` is called after widget is shown

**Performance problems:**
- Reduce `blurRadius` (15-25 is typical)
- Use `blurPicSize` parameter to scale down large images
- Avoid applying to very large widgets

**Multi-monitor issues:**
- AcrylicBrush automatically handles multi-monitor setups
- Ensure widgets are properly positioned on their screens

**Memory leaks:**
- AcrylicEffect objects are designed to be owned by their parent widgets
- No special cleanup needed when parent is destroyed

## Performance Tips

:::warning
**Performance Guidelines**: Follow these recommendations to ensure smooth performance while maintaining visual quality.
:::

1. **Use appropriate blur radius**: 15-25 for most cases, 30+ for heavy blur
2. **Scale large images**: Use `blurPicSize` parameter for optimization
3. **Avoid frequent updates**: Only grab screen when necessary
4. **Use smaller widgets**: Apply effects to specific regions rather than entire windows
5. **Cache backgrounds**: Reuse blurred images when possible
