# App showcase

Every screenshot below is a real, runnable app from the repo's `examples/PySide6/` folder — captured from the app itself, not a mockup. Click any screenshot to expand it. Featured applications first; the single-widget demos follow.

Apps marked **PATREON** ship their full source to [supporters](https://www.patreon.com/c/spinntv) — each one is posted individually on Patreon with its source attached, and any paid tier has access. Everything else is in the public repo.
