# QCustomSkeleton

![QCustomSkeleton screenshot](/img/showcase/skeleton.png)

`QCustomSkeleton` — a shimmering loading placeholder.

A rounded shape (line / rect / circle) with a moving shimmer, shown while
real content loads. Colours come from tokens via qproperty (baseColor /
highlightColor set by skeleton_qss).

---

## Import

```python
from Custom_Widgets.QCustomSkeleton import QCustomSkeleton
```

Also available from the **Qt Designer** palette — every property below is settable in Designer and saved into the `.ui` file.
