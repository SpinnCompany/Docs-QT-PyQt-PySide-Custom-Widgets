# QCustomEmbededWindow (renamed)

:::warning Renamed — spelling corrected
`QCustomEmbededWindow` was a misspelling of **embedded**. The widget is
[**`QCustomEmbeddedWindow`**](./QCustomEmbeddedWindow.mdx), with two `d`s.

This page is kept so existing links keep working. Everything it used to
document now lives on the correctly-spelled page.
:::

The import shown here previously does not work:

```python
# wrong — no such module
from Custom_Widgets.QCustomEmbededWindow import QCustomEmbededWindow
```

Use:

```python
from Custom_Widgets.QCustomEmbeddedWindow import QCustomEmbeddedWindow
```

See **[QCustomEmbeddedWindow](./QCustomEmbeddedWindow.mdx)** for the full
reference — properties, signals, theming and examples.
